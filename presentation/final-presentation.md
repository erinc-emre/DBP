# Final presentation

The deck is **`slides.md`** (Slidev). Run it with:

```bash
npx slidev presentation/slides.md         # live present at http://localhost:3030
npx slidev export presentation/slides.md  # -> PDF
```

- Images live in `presentation/assets/` (committed).
- The demo video is produced by the add-on's **Render Video** button into
  `renders/` (git-ignored) — reference the latest `flight_chase_*.mp4`.
- Fill in `<Your Name>` on the title slide.
